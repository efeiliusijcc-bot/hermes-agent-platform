# Hermes 离线 Agent 平台基础设施详细设计方案

版本：V1.0

目标： 构建一个企业内网离线运行的 Agent 基础平台，以 Hermes Agent
Runtime 为执行核心，以大模型服务为推理能力，通过
Agent、Skill、MCP、Knowledge、Memory
等模块组合，实现可配置、可隔离、可扩展的 AI 工作单元。

------------------------------------------------------------------------

# 一、建设目标

## 1. 核心目标

平台需要支持：

-   离线部署
-   私有大模型调用
-   Agent创建
-   Agent隔离运行
-   Skill动态加载
-   MCP工具绑定
-   文件和数据库数据访问
-   Agent API调用
-   Agent执行过程追踪

最终实现：

    创建一个Agent

    ↓

    配置角色

    ↓

    绑定Skill

    ↓

    绑定MCP

    ↓

    绑定知识源

    ↓

    发布调用接口

    ↓

    执行企业任务

------------------------------------------------------------------------

# 二、核心设计思想

## Agent不是聊天机器人

本平台中的Agent定义：

    Agent =

    角色定义
    +
    模型配置
    +
    Prompt规则
    +
    Skill能力
    +
    MCP工具
    +
    Knowledge知识
    +
    Memory记忆
    +
    权限边界

Agent类似企业中的一个数字员工。

例如：

    研发Agent

    能力:
    - 代码分析
    - Git查询
    - 文档总结

    工具:
    - Git MCP
    - Jira MCP

    知识:
    - 技术规范库

# 四、容器规划

## 1. agent-api

平台控制服务。

职责：

-   Agent CRUD
-   Agent配置管理
-   调度Hermes
-   生成调用接口
-   管理运行记录

接口：

创建Agent：

    POST /api/agents

运行Agent：

    POST /api/agents/{id}/run

查询：

    GET /api/agents

------------------------------------------------------------------------

## 2. hermes-runtime

Agent执行核心。

职责：

-   接收任务
-   加载上下文
-   调用模型
-   调用工具
-   执行Skill

不负责：

-   用户管理
-   Agent管理
-   数据存储

------------------------------------------------------------------------

## 3. model-gateway

作用：

隔离Agent和模型。

例如：

    Hermes

     |

    Model Gateway

     |

    Qwen300B

优势：

以后可以切换：

-   Qwen
-   DeepSeek
-   Llama
-   GLM

------------------------------------------------------------------------

## 4. mcp-gateway

统一工具入口。

结构：

    Agent

     |

    MCP Gateway

     |

    ----------------

    Database MCP

    File MCP

    Git MCP

    API MCP

作用：

-   工具注册
-   工具隔离
-   调用日志

------------------------------------------------------------------------

## 5. knowledge-service

负责知识能力。

功能：

-   文档解析
-   文档切片
-   Embedding
-   向量搜索

支持：

    PDF

    Word

    Markdown

    Excel

# 六、角色控制机制

Agent角色由多层组成。

## 1. Role

定义身份：

    你是一名财务分析专家

------------------------------------------------------------------------

## 2. System Prompt

控制行为。

例如：

    你的职责:

    1. 分析数据
    2. 提供结论
    3. 输出报告


    限制:

    不能编造数据

------------------------------------------------------------------------

## 3. Skill

控制做事方法。

例如：

    市场分析Skill

    流程:

    1. 理解主题

    2. 扩展关键词

    3. 查询数据

    4. 总结

------------------------------------------------------------------------

## 4. MCP

控制实际能力。

例如：

允许：

    读取数据库

    查询文件

禁止：

    修改生产数据

------------------------------------------------------------------------
